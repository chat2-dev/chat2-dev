# Blog Writing Website

## ✨ Overview

This project aims to create a **text editor** where users can write, edit, and post blogs directly to a website. It is designed to simplify the blogging process by providing an intuitive and user-friendly interface.

## 🚀 Features

- 📝 Write and edit blogs with a rich text editor.
- 🌐 Post blogs directly to the website.
- 📂 Save drafts for later editing.
- 🔍 Preview blogs before publishing.

## 🌱 Learning Journey

I’m currently learning **JavaScript** to build and enhance this project. This project is a hands-on way to improve my skills and create something meaningful.

## 🛠️ Technologies Used

- **HTML** for structuring the web pages.
- **CSS** for styling the interface.
- **JavaScript** for adding interactivity and functionality.
